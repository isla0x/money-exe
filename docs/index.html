C:\> money.exe /help

money.exe

한 줄 명령어로 쓰는 터미널 가계부예요. -4500 커피 한 줄이면 기록 끝. 이번 달 예산은 "로컬 디스크 (C:)" 용량처럼 줄어들어요.

명령어

명령어설명
-4500 커피쓴 돈 기록. 금액과 메모 순서는 자유 (커피 4500), 1.2만 · 3천원 도 OK. 태그는 메모를 보고 알아서 붙어요 (#카페 #식비 #교통 …). 직접 붙이려면 #태그.
budget 700000한 달 예산. 디스크 막대가 80% 넘으면 노랑, 넘기면 빨강 + "디스크 공간 부족" 창. budget 0 은 끄기.
budget 15만 /week주간 예산. 매주 월요일에 디스크가 다시 비워져요. budget /month 로 되돌려요.
dir이번 달 디스크와 기록 보기
stats [달]태그별 사용량(폴더 크기처럼)과 최근 6개월
print [달]그 달 내역을 영수증처럼 한 줄씩 출력. 사진으로 저장 · 공유
undo마지막 기록 지우기 (목록의 rm 을 두 번 눌러도 지워져요)
mode dark화면 밝기: dark · light · auto(폰 설정)
upgradePRO (아이폰): 홈 화면 · 잠금화면 위젯을 한 번 결제로
restore예전에 산 PRO 다시 불러오기

자주 묻는 질문

기록은 어디에 저장되나요?

폰 안에만 저장돼요. 서버가 없어서 어디로도 보내지 않아요. 그래서 앱을 지우면 기록도 함께 지워져요.

"이번 주 여유"는 어떻게 계산하나요?

한 달 예산일 때, 이번 주가 시작할 때 남아 있던 돈을 이번 달 남은 날에 고르게 나눈 것 중 이번 주 몫이에요. 초반에 많이 쓰면 이번 주 몫이 자동으로 줄어요.

위젯을 추가했는데 "Access is denied." 가 나와요

위젯은 PRO 기능이에요. 앱에서 upgrade 를 입력해 주세요. 이미 샀다면 restore 로 복원할 수 있어요.

위젯은 어떻게 추가하나요?

홈 화면을 길게 누르기 → 편집 → 위젯 추가 → money.exe. 잠금화면은 잠금화면을 길게 누르기 → 사용자화 → 잠금 화면 → 위젯.

영수증 사진 저장이 안 돼요

설정 → money.exe → 사진에서 "사진 추가"를 허용해 주세요.
